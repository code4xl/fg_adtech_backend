Ocean Ads RTB Platform

Welcome to our Real-Time Bidding test environment. This page demonstrates the complete Ocean Ads SDK integration with live RTB endpoints and ad serving capabilities.

The SDK automatically detects ad slots using the data-ocean-slot attribute and initiates bid requests to our RTB engine at http://localhost:3001/rtb/bid-request.

How It Works

  1. SDK Initialization: Loads configuration from CDN
  2. Slot Detection: Finds all ad slots on the page
  3. Bid Requests: Sends RTB requests for each slot
  4. Ad Rendering: Displays winning creatives
  5. Tracking: Reports impressions and interactions
